# KORTANGNOI — Requirements

## ภาพรวม

เว็บรับโดเนทสำหรับสตรีมเมอร์ในกลุ่มเพื่อนและคนรอบตัว ใช้ฟรี เงินโอนตรงจากผู้บริจาคเข้า PromptPay ของสตรีมเมอร์ ระบบตรวจสลิปอัตโนมัติแล้วขึ้น alert บน OBS ระหว่างไลฟ์ (Twitch, YouTube, TikTok Live ผ่าน OBS)

## ปัญหาที่แก้

1. เว็บโดเนทของคนอื่นต้องเติมเครดิตหรือหักค่าธรรมเนียม
2. ปรับแต่ง config ได้จำกัด
3. อยากเก็บประวัติโดเนทและส่งต่อไประบบของตัวเอง (webhook) ได้

## ผู้ใช้

| บทบาท        | คือใคร                 | ใช้ผ่าน                       |
| ------------ | --------------------- | --------------------------- |
| **สตรีมเมอร์** | เจ้าของโปรเจกต์และเพื่อน  | PC: dashboard + OBS overlay |
| **ผู้บริจาค**   | ผู้ชมไลฟ์ ไม่ต้องสมัครสมาชิก | มือถือเป็นหลัก                  |
| **แอดมิน**    | เจ้าของโปรเจกต์         | PC: หน้าดูโควตา SlipOK        |

## หลักการสำคัญ

- **เงินไม่ผ่านระบบเรา** โอนตรงเข้าบัญชีสตรีมเมอร์ ระบบทำหน้าที่ตรวจสอบและบันทึกเท่านั้น
- **ไม่มีค่าธรรมเนียม** ตรวจสลิปด้วย SlipOK key กลาง (แพ็กเกจฟรี 100 สลิป/เดือน รวมทุกคน) สตรีมเมอร์ไม่ต้องกรอก API key
- **ไม่มีรายการไหนหายเงียบ** ถ้าตรวจอัตโนมัติไม่ได้ ต้องเข้าคิว "รอตรวจ" ให้สตรีมเมอร์ตัดสินใจเสมอ
- **ง่ายสำหรับผู้บริจาค** ทำบนมือถือจบใน 3 ขั้น: กรอก → โอน → แนบสลิป

## Feature MVP

### สตรีมเมอร์

- **F1 ล็อกอิน:** ด้วย Google หรือ Discord, ตั้ง username สำหรับลิงก์โดเนท
- **F2 ตั้งค่าช่องทางรับเงิน:** ประเภท PromptPay (เบอร์โทร/เลขบัตร), เลข PromptPay, ชื่อบัญชีไทย, ชื่อบัญชีอังกฤษ (ไม่บังคับ), สวิตช์แสดง/ซ่อนชื่อบัญชีในหน้าโดเนท, ยอดขั้นต่ำ, เปิด/ปิดรับโดเนท
- **F3 ตั้งค่า alert:** ค้นหาและเลือก GIF ในเว็บ (KLIPY) หรืออัปโหลดรูป/GIF เอง, ระยะเวลาแสดง, ปุ่มทดสอบ alert
- **F4 Overlay OBS:** ลิงก์ลับสำหรับ Browser Source, ปุ่มคัดลอก และปุ่มสร้างลิงก์ใหม่ (กรณีลิงก์หลุด)
- **F5 ประวัติโดเนท:** รายการพร้อมสถานะ (ผ่าน / รอตรวจ / ไม่ผ่าน), ตัวกรองสถานะ, ยอดรวมวันนี้และเดือนนี้
- **F6 อนุมัติ/ปฏิเสธ:** สำหรับรายการ "รอตรวจ" พร้อมดูรูปสลิปและเหตุผลที่ระบบตรวจไม่ผ่าน อนุมัติแล้วขึ้น alert และส่ง webhook เหมือนผ่านอัตโนมัติ
- **F7 Discord webhook:** ใส่ URL webhook (ไม่บังคับ) ส่งข้อมูลโดเนทที่ผ่านแล้ว พร้อมปุ่มทดสอบ

### ผู้บริจาค

- **F8 หน้าโดเนท `/{username}`:** กรอกชื่อที่แสดง, ยอด (≥ ขั้นต่ำ), ข้อความ → ได้ QR PromptPay ล็อกยอด + ปุ่มบันทึก QR
- **F9 แนบสลิป:** อัปโหลดรูปสลิป แล้วแสดงผล: สำเร็จ / รอสตรีมเมอร์ตรวจ / ไม่ผ่าน (พร้อมเหตุผลที่เข้าใจได้)

### ระบบ

- **F10 ตรวจสลิป:** อ่าน QR จากรูป → เช็กสลิปซ้ำใน DB → ส่ง SlipOK → เช็กยอด, บัญชีผู้รับ (เลข PromptPay ที่ถูกปิดบางหลัก + ชื่อบางส่วน), เวลาโอนอยู่หลังสร้างรายการ → ตัดสินผล
- **F11 Alert realtime:** โดเนทที่ผ่านแล้วขึ้น overlay ภายในไม่กี่วินาที แสดงทีละอันตามคิว
- **F12 หน้าแอดมิน:** ดูโควตา SlipOK คงเหลือและวันหมดอายุ

## สิ่งที่ไม่ทำในรอบแรก (v2)

- ตรวจสลิปซ้ำอัตโนมัติหลัง error 1010/1009 (รอบแรกให้เข้าคิวรอตรวจ)
- TTS, goal bar, ตารางอันดับ
- alert แยกตามช่วงยอดเงิน, ธีม alert, กรองคำหยาบ
- TrueMoney / ซองอั่งเปา, payment gateway
- ส่งต่อแจ้งเตือนเงินเข้าจาก Android
- แอปมือถือ, หลายภาษา

## อนาคต

- **Discord bot:** ทำทุกอย่างผ่าน Discord (ดูยอด, อนุมัติ, ตั้งค่า, แจ้งเตือน) ด้วย slash commands แบบ HTTP — MVP ต้องแยก business logic ไว้ใน service layer และเก็บ Discord ID ตั้งแต่แรก

## ข้อจำกัดและความเสี่ยง

| เรื่อง                                   | ผลกระทบ                     | รับมือ                                                       |
| -------------------------------------- | --------------------------- | ---------------------------------------------------------- |
| สลิป BBL/SCB ต้องรอ ~8 นาที (SlipOK 1010) | alert ไม่ขึ้นทันที               | เข้าคิวรอตรวจ, v2 ทำ retry อัตโนมัติ                            |
| โควตา SlipOK ฟรี 100/เดือนรวมทุกคน        | เกินแล้วเสีย 1 บาท/สลิป         | เช็กซ้ำก่อนเรียก API, จำกัดการส่ง, หมดโควตาให้เข้าคิวรอตรวจ         |
| SlipOK ล่ม / ธนาคารขัดข้อง (1009)         | ตรวจอัตโนมัติไม่ได้              | เข้าคิวรอตรวจ                                                |
| Supabase free หยุดโปรเจกต์หลังไม่ใช้ 7 วัน   | เว็บใช้ไม่ได้จนกว่าจะกดเปิด       | แจ้งในคู่มือแอดมิน                                              |
| Vercel Hobby สำหรับใช้แบบไม่เชิงพาณิชย์      | ถ้าเก็บเงินค่าบริการต้องย้ายแพ็กเกจ | ใช้ฟรีในกลุ่มเพื่อนเท่านั้น                                         |
| กฎหมายเรื่องรับชำระแทน                    | ถ้าเปิดสาธารณะ                | เงินไม่ผ่านระบบเรา; ปรึกษาผู้รู้ก่อนขยาย                            |
| ข้อมูลส่วนตัวผู้โอน (ชื่อจริงจาก SlipOK)        | หลุดขึ้นจอไลฟ์                  | alert ใช้เฉพาะชื่อที่ผู้บริจาคกรอก, ชื่อจริงเห็นเฉพาะสตรีมเมอร์ในหน้าตรวจ |

## เกณฑ์ว่า MVP เสร็จ

1. เพื่อน 2 คนขึ้นไปสมัครและตั้งค่าได้เองโดยไม่ต้องถาม
2. โอนจริงด้วยสลิป KBank/KTB แล้ว alert ขึ้นใน OBS ภายใน 10 วินาทีหลังแนบสลิป
3. สลิปซ้ำ, ยอดไม่ตรง, โอนผิดบัญชี ถูกปฏิเสธทั้งหมด
4. รายการที่ตรวจอัตโนมัติไม่ได้ เข้าคิวรอตรวจและอนุมัติได้
5. `npm run verify` ผ่าน และ deploy บน Vercel ใช้งานได้จริงบนมือถือและ PC
