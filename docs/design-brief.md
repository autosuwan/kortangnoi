# KORTANGNOI — Design Brief

เว็บรับโดเนทสำหรับสตรีมเมอร์ในกลุ่มเพื่อน เงินโอนตรงเข้า PromptPay ของสตรีมเมอร์ ไม่หักค่าธรรมเนียม ตรวจสลิปอัตโนมัติ แล้วขึ้น alert บน OBS

## Feature

### MVP

1. ล็อกอินด้วย Google / Discord (Supabase Auth)
2. หน้าตั้งค่าช่องทางรับเงิน: ประเภท PromptPay (เบอร์/เลขบัตร), เลข PromptPay, ชื่อบัญชีไทย + อังกฤษ (ไม่บังคับ), สวิตช์แสดง/ซ่อนชื่อ, ยอดขั้นต่ำ, Discord webhook (ไม่บังคับ)
3. ตั้งค่า alert: **ค้นหา GIF ในเว็บ** (KLIPY API ผ่าน server route) หรืออัปโหลดรูป/GIF เอง 1 รูป (มีค่าเริ่มต้นให้), ระยะเวลาแสดง
4. หน้าโดเนทสาธารณะ `/{username}`: กรอกชื่อ ยอด ข้อความ → QR ล็อกยอด → แนบสลิป → แสดงผล
5. ตรวจสลิป: อ่าน QR เอง → เช็กซ้ำใน DB → SlipOK (key กลาง) → เช็กยอด, ผู้รับ, เวลาโอน → ผ่าน / ไม่ผ่าน / รอตรวจ
6. Overlay OBS `/overlay/{secret}`: กล่องข้อความเด้ง มีรูป/GIF, ชื่อ, ยอด, ข้อความ, เสียง
7. หน้าประวัติโดเนท + ปุ่มอนุมัติ/ปฏิเสธรายการรอตรวจ
8. ส่ง webhook ไป Discord เมื่อโดเนทผ่าน
9. หน้า admin ดูโควตา SlipOK

### v2

ตรวจสลิปซ้ำอัตโนมัติ (error 1010/1009), TTS, goal bar, ตารางอันดับ, alert ตามช่วงยอด, กรองคำหยาบ, ธีม alert, TrueMoney, ส่งต่อแจ้งเตือนจาก Android

### อนาคต: ย้ายการใช้งานไป Discord

หลังระบบเว็บเสร็จ จะทำ Discord bot ให้สตรีมเมอร์ทำทุกอย่างผ่าน Discord ได้ (ดูยอด, อนุมัติ/ปฏิเสธรายการรอตรวจ, ตั้งค่า, รับแจ้งเตือน) สิ่งที่ต้องเตรียมตั้งแต่ MVP:

- business logic อยู่ใน service layer (`src/server/services/`) แยกจาก route handler และ UI เพื่อให้ bot เรียกใช้ซ้ำได้
- ล็อกอินด้วย Discord ได้ตั้งแต่แรก เก็บ Discord user ID ไว้ผูกบัญชี
- bot ใช้ Discord Interactions แบบ HTTP endpoint (slash commands) ซึ่งรันบน Vercel ได้ ไม่ต้องมี server เปิดค้าง

## Visual direction

**อารมณ์:** มินิมอล อบอุ่น สะอาด — Clean UI

**Reference หลัก: สไตล์ Supabase (supabase.com + Supabase Studio)** — เอาโครงและภาษาการออกแบบมาใช้ แต่สี ฟอนต์ และอารมณ์อบอุ่นตามบรีฟนี้ ไม่ใช้โลโก้/ภาพ/ชื่อของ Supabase:

- พื้นเกือบขาว แยกส่วนด้วย **เส้นขอบ 1px บางๆ ไม่ใช้เงา**
- การ์ดมีขอบ 1px มุมโค้ง 12–16px, ปุ่มและอินพุตมุม 8px ปุ่มเล็กกะทัดรัด (สูง 32–36px)
- หัวข้อใหญ่น้ำหนัก **500** (ไม่หนา) หัวข้อสองบรรทัด: บรรทัดแรกสีดำ บรรทัดสองสีส้ม
- เนื้อหาสีเทากลาง เน้นคำสำคัญด้วยสีดำ
- ไอคอนเส้น (Lucide) คู่หัวข้อการ์ด, ภาพประกอบเป็นลายเส้นบางสีเทา
- ใช้ฟอนต์ mono กับข้อมูลเทคนิค: ลิงก์ overlay, เลขอ้างอิง, ยอดในตาราง
- **Dashboard แบบ Studio:** sidebar ซ้ายแคบเป็นไอคอนอย่างเดียว (มี tooltip), หัวหน้ามี breadcrumb, หน้าตั้งค่าเป็นฟอร์มแบบ label ซ้าย–ช่องกรอกขวา แบ่งหมวดด้วยเส้นขอบ, ปุ่มบันทึกอยู่ท้ายแต่ละหมวด
- ตารางหนาแน่นแบบ Studio: แถวเตี้ย เส้นคั่นบาง badge สถานะเล็ก
- สวิตช์ light/dark อยู่ล่าง sidebar

ยังเก็บจาก reference เดิม: ตัวเลขยอดเงินใหญ่ ส่วนทศนิยมสีเทา (เช่น ฿3,200.80), จุดสีบอกสถานะ

### ฟอนต์

- **Noto Sans Thai** (ไทย) + **Noto Sans** (อังกฤษ/ตัวเลข) จาก Google Fonts
- หัวข้อ 600–700, เนื้อหา 400, ตัวเลขยอดเงินใช้ tabular numbers

### รูปทรง

- การ์ด radius 12–16px + ขอบ 1px, ปุ่ม/อินพุต 8px, ไม่ใช้เงา (ยกเว้น popover/dialog เงาบางมาก)
- หน้า marketing/หน้าโดเนทโปร่ง, dashboard กะทัดรัดแบบ Studio

## หน้าหลัก

1. **Dashboard สตรีมเมอร์:** ยอดรวมวันนี้/เดือนนี้ (ตัวเลขใหญ่), โดเนทล่าสุด, รายการรอตรวจ, ลิงก์หน้าโดเนท + ลิงก์ overlay (ปุ่มคัดลอก)
2. **ตั้งค่าช่องทางรับเงิน:** การ์ดแบบหน้าตั้งค่า Hiwdo, แถบ "ยังไม่บันทึก" ด้านล่างเมื่อมีการแก้
3. **ตั้งค่า alert:** อัปโหลดรูป/GIF + ปุ่มทดสอบ alert
4. **ประวัติโดเนท:** ตาราง + ตัวกรองสถานะ
5. **หน้าโดเนท (มือถือเป็นหลัก):** การ์ดเดียวกลางจอ, ขั้นตอน 1-2-3 (กรอก → สแกนจ่าย → แนบสลิป), ปุ่มใหญ่กดง่าย

## Alert overlay

- พื้นหลังโปร่งใส (ใช้ใน OBS Browser Source)
- กล่องการ์ดสีขาว ขอบ 1px มุม 16px เด้งขึ้นกลางจอ (scale + fade) แล้วหายเอง
- บนสุด: รูป/GIF ของสตรีมเมอร์
- **ชื่อผู้บริจาค** + **ยอดเงินสีส้มตัวใหญ่**
- ข้อความด้านล่าง ตัดถ้ายาวเกิน
- เล่นเสียง 1 เสียงตอนเด้ง
- ถ้ามีหลายโดเนทพร้อมกัน แสดงต่อคิวทีละอัน
